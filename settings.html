🌐 Remote Access / Tailscale

MastARR can connect to Sonarr and Radarr through Tailscale by using the Tailscale address as the service URL.

  1. Install tailscaile on this device.
  2. Install Tailscale on the machine hosting Sonarr, Radarr, or both.
  3. Sign both devices into the same Tailscale network.
  4. Click the Test Connection button to confirm MastARR can reach each service.
